## Features
- 12 playable characters (Frog, Bear, Moose, Pig, Axolotl + more)
- 48 unlockable skins earned with in-game coins
- Shield, Magnet, and Coin Doubler power-ups
- Original chiptune soundtrack
- Works on desktop, iPhone, iPad, and Android
- Single HTML file — no install needed

## How to Play
Tap / Space / ↑ to jump · Hold to charge · Double-tap to quick hop · Hold ↓ to duck
